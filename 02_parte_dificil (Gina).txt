NOMBRE DEL SISTEMA:
App Detección Prod

PARTE DEL SISTEMA QUE CONSIDERAMOS MÁS DIFÍCIL:
Trazabilidad de decisiones comerciales sobre productos críticos.

¿POR QUÉ ES DIFÍCIL? (3 a 5 líneas, en lenguaje de negocio, NO en lenguaje técnico):
La parte más difícil no es que el mercaderista registre un producto, sino asegurar que ese registro termine en una decisión comercial correcta, validada y medible. Un producto con fecha corta puede requerir descuento, bandeo, cambio de precio, retiro o seguimiento, pero si la información está incompleta o desordenada se pueden tomar decisiones tardías, duplicadas o equivocadas. La dificultad está en coordinar a mercaderista, supervisor, vendedor y gerencia con la misma información: fecha, cantidad, precio, acción aplicada, responsable y resultado. Si esta trazabilidad falla, la empresa no sabe si perdió dinero, si recuperó venta o si repitió el mismo error.

ESCENARIO CONCRETO:
- Actor: Mercaderista, Supervisor Regional y Vendedor Comercial.

- Punto de partida (datos o situación):
Durante una visita a una sala de supermercado, el mercaderista detecta varias unidades de un producto con vencimiento cercano. Además nota que el producto sigue con precio regular, aunque debería tener una acción comercial para acelerar su venta. El vendedor necesita decidir si se aplica descuento o bandeo, y el supervisor debe validar que la información sea correcta antes de cerrar el caso.

- Pasos que ocurren:
1. El mercaderista registra el producto en la sala, ingresando fecha de vencimiento, cantidad afectada, precio actual, evidencia fotográfica y acción sugerida.
2. El sistema clasifica el caso como producto crítico o por vencer y deja visible si existe o no cambio de precio propuesto.
3. El supervisor revisa la evidencia, confirma si los datos son suficientes y valida o solicita corrección.
4. El vendedor define la acción comercial final: descuento, bandeo, promoción, retiro, reubicación o mantener sin acción justificada.
5. El sistema actualiza el estado del producto y deja trazado el precio anterior, el nuevo precio, la acción aplicada, los responsables y el resultado esperado.

- Resultado esperado:
El producto queda registrado con información completa, acción comercial definida, precio controlado y responsable asignado. Supervisión y gerencia pueden ver el estado del caso en tiempo real, saber si el producto fue intervenido y medir posteriormente si la acción redujo merma, aceleró rotación o evitó devolución.

REGLAS / RESTRICCIONES QUE NO PUEDEN ROMPERSE:
1. Un producto crítico no puede cerrarse si no tiene acción comercial definida o una justificación clara de por qué queda sin acción.
2. Si hay cambio de precio, siempre deben registrarse precio actual, nuevo precio, porcentaje de descuento, motivo y responsable de aprobación.
3. Todo registro crítico debe tener evidencia fotográfica suficiente para evitar dudas sobre producto, sala, cantidad o estado.
4. El supervisor debe validar los registros críticos antes de que se consideren cerrados.
5. El historial del producto no debe perderse: debe mostrar detección, cambios, validaciones, acciones y resultado final.

¿CÓMO MEDIRÍAMOS QUE FUNCIONA? (criterio observable en lenguaje de negocio):
Mediríamos que funciona si los productos críticos dejan de perderse entre mensajes, si los registros llegan completos y si cada producto tiene una acción comercial clara. El sistema debe reducir el tiempo de validación del supervisor, disminuir productos vencidos sin acción, evitar descuentos duplicados y mostrar cuántos productos fueron recuperados mediante descuento, bandeo, promoción o cambio de precio. También debe permitir comparar el antes y después: precio original versus nuevo precio, cantidad afectada versus cantidad recuperada, y merma potencial versus merma evitada.
