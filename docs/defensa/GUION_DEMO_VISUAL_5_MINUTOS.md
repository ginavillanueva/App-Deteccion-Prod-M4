# Guion de defensa — demo visual de dos features

## Apertura

Esta demo muestra dos features aplicadas de App Detección Prod. La primera corresponde al registro visual del mercaderista y la segunda integra la validación supervisora con un dashboard gerencial avanzado.

## Problema

El proceso actual usa reportes dispersos, fotos sin estándar, WhatsApp y Excel. Esto impide trazabilidad, control de precios, seguimiento de acciones comerciales y medición de impacto financiero.

## Feature 1

El mercaderista registra un producto próximo a vencer desde una interfaz estructurada. Al guardar, la aplicación calcula riesgo, score, SLA, valor financiero en riesgo, valor intervenido, descuento y genera eventos.

## Feature 2

El supervisor selecciona un caso, revisa evidencia y precio, valida con comentario y deja trazabilidad. Luego gerencia visualiza un dashboard con filtros nacionales y regionales, gráficos, ranking e insights.

## Trazabilidad

La demo mantiene relación entre FSD, Design Doc, ADR, prompt de implementación, código y tests.

## Cierre

El valor de la solución es convertir un proceso informal y reactivo en un sistema trazable, medible y útil para decisiones operativas, tácticas y gerenciales.
