# Guía de demo visual con evidencia fotográfica

## Objetivo

Demostrar el flujo aplicado del producto desde cero, con dos features implementadas y trazables.

## Flujo para evaluación

1. Reiniciar demo.
2. Ingresar a **Mercaderista registra**.
3. Completar los datos del producto crítico.
4. Adjuntar una evidencia fotográfica de góndola, etiqueta o producto.
5. Registrar el caso crítico.
6. Revisar el cálculo de riesgo y la tabla de variables.
7. Ingresar a **Bandeja supervisor**.
8. Seleccionar el caso y revisar la evidencia visual.
9. Validar como supervisor.
10. Ingresar a **Gerencia analiza** y revisar KPIs, filtros y gráficos.
11. Ingresar a **Eventos y trazabilidad** para verificar la conexión FSD → DD → ADR → Prompt → Código → Tests.

## Qué demuestra la evidencia fotográfica

La evidencia deja de ser solo texto. El mercaderista puede adjuntar una imagen, verla antes de registrar el caso y el supervisor puede observarla antes de aprobar. Esto representa el reemplazo de fotos dispersas por WhatsApp por evidencia asociada al ID del caso.
