# Prompts versionados - App Detección Prod

Este directorio contiene prompt-contratos derivados de especificaciones aprobadas. Cada prompt sigue la plantilla docente:

1. Metadatos.
2. Role.
3. Task.
4. Context.
5. Reasoning estructurado.
6. Stop condition.
7. Output.
8. Invariantes.
9. Failure modes.
10. Guardrails.
11. Trazabilidad.
12. Prompt tests.
13. Instrumentación.
14. Versionado.
15. Revisión humana.

Los prompts no son conversaciones libres; son contratos auditables para agentes IA.

## Reglas críticas

- IA no cambia precios.
- IA no aprueba descuentos.
- IA no retira productos.
- IA no cierra casos.
- Todo cambio de precio requiere trazabilidad y revisión humana.
- Todo output crítico debe mapearse a FSD/DTI/ADR/POC.
