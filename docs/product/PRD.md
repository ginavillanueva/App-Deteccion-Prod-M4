# PRD vivo — App Detección Prod

## PRD-REQ-001 — Registro estructurado de producto crítico

El sistema debe permitir registrar un producto próximo a vencer con tienda, producto, lote, fecha de vencimiento, cantidad, precio actual, acción comercial y evidencia.

## PRD-REQ-002 — Control de cambio de precio

El sistema debe auditar precio actual, precio nuevo, diferencia, porcentaje de descuento, aprobación y motivo del cambio de precio.

## PRD-REQ-003 — Priorización operativa

El sistema debe clasificar el riesgo del caso en BAJO, MEDIO o ALTO mediante reglas explicables.

## PRD-REQ-004 — Dashboard gerencial básico

El sistema debe mostrar KPIs operativos y financieros básicos: casos totales, riesgo alto, cantidad intervenida, valor financiero en riesgo, cambios de precio y acciones pendientes.

## PRD-REQ-005 — Trazabilidad documental y técnica

El sistema debe mantener trazabilidad entre PRD, FSD, Design Doc, ADR, prompt, código, tests y DTP.
